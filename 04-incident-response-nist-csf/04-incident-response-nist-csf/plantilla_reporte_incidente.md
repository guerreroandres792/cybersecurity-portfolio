# Plantilla Estándar de Reporte de Incidentes (SOC Tier 1 / 2)

| Campo | Detalle |
| :--- | :--- |
| **Identificador del Incidente** | `INC-AAAA-XXXX` |
| **Fecha / Hora de Registro** | `AAAA-MM-DD HH:MM:SS` |
| **Analista Responsable** | Nombre y Apellido |
| **Nivel de Severidad** | [Baja / Media / Alta / Crítica] |
| **Categoría del Incidente** | [Phishing / Malware / Denegación de Servicio / Acceso No Autorizado] |
| **Activos / Hosts Afectados** | Nombre de host, IP interna, usuario asociado |
| **Indicadores de Compromiso (IoC)** | Hashes (MD5/SHA256), IPs públicas atacantes, dominios maliciosos |
| **Acciones de Contención Ejecutadas** | [Aislamiento de red, bloqueo de IP en FW, reinicio de credenciales] |
| **Estado Actual** | [En Investigación / Contenido / Erradicado / Cerrado] |
